01

9/21｜Kobe → Tainan

移動を終えたら、夕日・ホテル・台南夜景・夜市へ。

05:54

JR 六甲道 → 三ノ宮 休日ダイヤ想定

普通列車で約6分。9/21は祝日ダイヤ扱い。06:00頃三ノ宮着を想定。駅から空港バス乗り場へ。

06:20

神戸三宮 → 関西空港 T2 推奨

リムジンバス。第2ターミナル 07:36着。もし満席なら 06:30→07:46、06:40→08:06もバックアップ。朝便は混雑注意。

公式時刻表
07:40

KIX T2 到着・チェックイン準備

Peach国際線は第2ターミナル。チェックイン可能時間は出発150〜50分前。10:45便なら最終チェックイン目安は09:55。

10:45

Peach MM025｜KIX T2 → 桃園 T1 予約済

到着予定 12:45（台湾時間）。受託手荷物あり。

12:45

入国・手荷物 → 悠遊卡チェック

到着ロビーのコンビニで、ちいかわ / ドラえもん等の悠遊卡があれば購入。無ければ無理に普通カードを買わず、Airport MRTは通常券でもOK。

13:45

Airport MRT A12 → A18 高鉄桃園駅 目安

入国所要時間で前後するため固定便にはしない。普通車は概ね15分間隔。THSR 15:10発に間に合うよう、14:30頃までのA18到着を目標。

15:10

THSR 651｜桃園 → 台南 予約済

16:32着。標準車・指定席、4号車 5D / 5E。T Expressは未発券のまま柔軟性を残す。

16:40

タクシーで Crowne Plaza Tainan へ

高鉄台南駅から安平は距離があるため、ここはタクシー優先。17:15〜17:25頃ホテル着を想定。

17:30

觀夕平台｜安平の海で夕日 映え

ホテルから車で数分。海・砂浜・空のグラデーションを撮る。9月下旬は日没が18時前なので、ホテル到着後は荷物だけ置いてテンポよく。

18:20

ホテルの温水プール＋サウナ

20m屋内温水プールは7:00〜22:00。プール後にサウナ、シャワー、着替えまでまとめてリセット。

20:00

神農街｜提灯と古い商家 夜写真

狭い路地、古い木造建築、カラフルな提灯。台南らしい「古い街 × 夜」の写真を30〜45分。

21:00

大東夜市｜台南ローカル食べ歩き 月曜営業

月・火・金に営業する広場型夜市。牛肉湯、虱目魚、担仔麺、蝦捲、地瓜球などをシェアして少量ずつ。

22:40

ホテル帰着

翌朝は四草があるので、夜市は深追いしすぎない。

02

9/22｜Tainan → Shifen → Jiufen

朝の自然・歴史から、午後は天燈と赤提灯の山城へ。

07:00

朝食・準備

ホテル朝食を使う場合は40分程度。朝食条件は予約プランで確認。07:45までにチェックアウトし、荷物はホテルへ預ける。

08:05

ホテル → 四草緑色隧道

タクシーで移動。08:15前後着を狙い、QRチケットなら紙券に引き換えて待機。

08:30

四草緑色隧道｜マングローブ船 最優先

航程約30分。平日は08:30〜16:00、約30人集まると出航。時間指定・座席指定ではないので、08:30〜09:20を「乗船待ち込み」の枠に。

前夜にホテルへ確認： コンシェルジュから四草（06-284-1610）へ「9/22朝の運航状況」を確認してもらうと安心。
09:30

安平樹屋＋德記洋行 映え・歴史

榕樹の気根が旧倉庫を飲み込む、台南らしい自然と歴史の共生。白い洋館の德記洋行も同じエリア。08:30〜17:30、全票NT$70。

10:20

安平老街を15分だけ

時間に余裕があれば、路地・蜜餞・蝦捲などを軽く覗く。10:35にはホテルへ戻る方向へ。

10:50

ホテルで荷物回収 → 高鉄台南駅へ

11:30〜11:40頃の駅到着を目標。12:13便なので、四草の待ち時間が延びたら安平老街をカット。

12:13

THSR 636｜台南 → 台北 予約済

13:59着。標準車・指定席、4号車 14D / 14E。

14:10

Palais de Chine Hotelへ・荷物だけ預ける

ホテルは台北駅北側。チェックイン15:00前でも、荷物を預けてすぐチャーターへ。

14:45

Klook貸切チャーター出発 6時間予約済

ホテル発・ホテル戻り。指定ルートは「十分でランタン → 九份」。渋滞に応じてドライバーと調整。

15:30

十分老街｜天燈上げ 45〜50分

線路沿いの店でランタンを選び、願い事を書く → 線路上でスタッフ撮影 → 点火 → リリース。列車通過時は一時中断するので、16:20頃までに出発したい。

17:00

九份老街｜昼→夕暮れ→赤提灯 主役

9/22の日没は17:49頃、薄明は18:12頃まで。まず外を歩き、海と斜面の町を撮る。阿妹茶樓は時間固定予約せず、渋滞と混雑を見て入る。

19:15

九份を出発 → 台北

ホテル20:15〜20:30頃を想定。チャーターは20:45までが6時間枠。

20:45

寧夏夜市｜台北の夜食 余力があれば

ホテルから近く、17:00〜23:30。蚵仔煎、地瓜球、魯肉飯などを軽めに。翌朝も食べるので「満腹にしすぎない」が正解。

22:15

ホテルへ マッサージは当日判断

前回の千里行は微妙だったため、今回は無理に同系統へ行かず、疲れ具合でSPA系を当日追加。

03

9/23｜Taipei → Kobe

台湾朝ごはん、台北101、台湾茶、小籠包、そして旬のマンゴーかき氷で締め。

08:00

チェックアウト・荷物預け

Palais de Chineのチェックアウトは11:00だが、朝から動くため先に済ませる。

08:15

台湾朝ごはん

豆漿（豆乳）、蛋餅（卵クレープ）、蘿蔔糕（大根もち）、燒餅など。阜杭豆漿は有名だが行列が長いことがあるので、30分以上なら近隣店へ切り替え。

09:20

タクシーで台北101へ

10:00入場を狙って早めに移動。チケット確認・入口移動の時間も含めて9:45頃の到着が安心。

10:00

台北101 展望台 10:00枠推奨

89Fの360°ビュー、高速エレベーター、巨大制振球を体験。朝一の枠で動くと、最終日の後半に余白を残しやすい。

11:05

四四南村｜101を外から撮る

1950年代の眷村建築と超高層101を同じ画面に。20分ほど写真優先で回る。

11:40

Zenique Yongkang｜小茶栽堂 前回の取りこぼし

台湾茶・茶菓子・ギフトが揃う旗艦店。木質の店内もきれい。滞在20分ほどでお土産候補をチェック。

12:20

金品茶樓｜小籠包ランチ 再訪

前回「美味しかった」実績あり。小籠包は薄皮の中に熱い肉汁が入る台湾旅行の王道。友達の初台湾にも◎。

13:15

冰讚（ピンザン）｜芒果雪花冰 行列次第

雙連街2號。旬の生マンゴーを、ミルク味のふわふわ雪花冰にたっぷり載せる台北の人気店。2026年は4/29から季節営業中で、9月はマンゴーシーズン内。待ち時間が30分を超えそうなら空港時間を優先してスキップ。

14:00

ホテルへ戻って荷物回収

冰讚からPalais de Chineは近い。14:10前後のホテル着を目標にして、預け荷物をピックアップ。

14:20

ホテル → A1台北駅 無料シャトル 事前予約推奨

11:00〜16:00の予約制。前日までに14時台の便を依頼。冰讚の行列が長い場合は、徒歩・タクシーでA1へ切り替える。

14:40

Airport MRT A1 → 桃園空港 T1

15:20前後の空港到着を想定。18:15便まで約3時間。荷物預け・出国後は最後のお土産タイム。

18:15

Peach MM028｜桃園 T1 → KIX T2 予約済

22:00到着予定。

22:47

KIX T2 → 神戸三宮 リムジンバス 間に合えば

23:00にT1を経由し、00:05神戸三宮着。受託手荷物・入国で間に合わない場合は、23:50 T2発のベイ・シャトル連絡バス → 00:00船 → 00:31神戸空港着をバックアップに。

00:05

神戸三宮 → 六甲道

深夜帯なので最終的にはタクシーが確実。旅行おつかれさま 🇹🇼

最終日の優先順位： 台北101 → 金品茶樓 → 空港移動は固定。Zenique・四四南村・冰讚は混雑に応じて短縮可能。冰讚は人気店なので、行列が長ければ無理をしない。

WHAT TO EAT

台湾ならではの食べ物

「どんな味？」が友達にも分かるように。台南は素材感、台北は朝食・小籠包・夜市で攻める。

牛肉湯｜台南

薄切りの新鮮な牛肉に熱い澄んだスープを注ぎ、余熱で火を通す台南名物。牛肉そのものの甘さを楽しむ。

台南感 ★★★★★

虱目魚粥｜台南

サバヒーを使った塩味のやさしい粥・スープ。台南の朝食文化を代表する魚料理。

ローカル度 ★★★★★

担仔麺｜台南

小ぶりの麺に肉そぼろ、海老などをのせる台南発祥の一杯。夜市でシェア向き。

食べ歩き向き ★★★★☆

蝦捲｜台南

海老や魚のすり身などを薄皮で巻いて揚げる。外はカリッ、中はプリッ。安平の定番。

安平名物 ★★★★☆

地瓜球｜夜市

さつまいも生地を丸く揚げた、外カリ中もち系の台湾夜市スナック。黄色・紫色も映える。

夜市感 ★★★★★

蛋餅＋豆漿｜台北朝食

薄い生地と卵を焼く蛋餅に、温かい豆乳。蘿蔔糕や燒餅も足して“台湾の朝”を完成。

台湾朝食 ★★★★★

小籠包｜金品茶樓

薄皮の中に肉餡と熱いスープ。前回おいしかった店を、今回は友達にも紹介する再訪枠。

安心の再訪 ★★★★★

寧夏夜市の小吃

蚵仔煎、魯肉飯、地瓜球など、台北の定番小吃を少量ずつ。2日目夜の追加ラウンド。

夜の台湾感 ★★★★★

芒果雪花冰｜冰讚

ミルク風味の雪花冰を細かく削り、旬の生マンゴーをたっぷり。マンゴーの収穫期に合わせて季節営業する、台湾の夏を代表するデザート。

台湾夏スイーツ ★★★★★

食べ方のコツ

2人旅なので「一人一品」より、一品をシェアして種類を増やすのがおすすめ。夜市では牛肉湯 → 蝦捲 → 麺 → 甘いもの、のように味を散らすと重くなりにくい。
